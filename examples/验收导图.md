# DSH 思维导图插件 · 验收导图

插件把对话里的 Markdown 大纲当作唯一真相，右侧栏只是同一份文件的另一个编辑器。

## 入口

- 右侧栏「开始」页的思维导图卡片
- 会话标题栏的思维导图按钮
- 每轮对话结束后的脑图小胶囊

## 编辑能力

- 双击节点就地改名
- Tab 加子节点，Enter 加同级
- 拖动节点换父级
- `/` 折叠分支
- 节点配色与备注

## 格式支持

- Markdown 标题层级 → 节点
- Markdown 列表缩进 → 节点
- `%%fold%%` 等标记原样保留
- `.xmind` 只读打开，可另存为 Markdown
